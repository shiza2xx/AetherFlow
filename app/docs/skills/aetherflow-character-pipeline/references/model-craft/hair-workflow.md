# Hair shape, roots, paint, and motion

Design hair with the whole head. Establish length, parting, face visibility, root placement, overlap, and undersides from accepted views. Follow strand centerlines root-to-tip; control width, thickness, and cross-section twist separately. Distinguish gaps inside one strand from intended overlap between separate strands; do not weld every strand together.

Check hairline, ears, nape, ties, and coverage from side/back. A normal change cannot fix reversed layering or protruding geometry. Fit bones to strand flow, keep roots/ties fixed, then test a few neighboring strands before expanding. Separate broad gradients, fine flow, highlights, and depth shadows; inspect UV seams and use distinct image destinations where overlap occurs. Check required body/outfit paths and state runtime limitations.
