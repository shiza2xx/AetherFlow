# Hands and fingers

Establish the accepted open-hand silhouette, palm thickness, finger lengths, thumb web, and nail shape from matched front/back/side references. Correct rest shape before weight tuning. Map knuckles and bend axes to circumferential support rows and longitudinal flow; the thumb has distinct axes and web transitions.

Test fist, pinch, partial bends, and return. Separate joint placement, topology, and weights. Preserve palm volume and web continuity. Treat nails as dependent fingertip geometry; matching counts do not prove attachment. For a local length correction, specify pivot, axis, displacement, and fade. Inspect rest/intermediate/required extreme/return, then save the tested mesh, rig, keys, nails, and ornaments together.
