# Mesh flow and skinning

Inspect rest shape before weights. Classify holes, internal/duplicate faces, normals, boundaries, and density separately; an open garment edge may be intentional. At each required bend, map bone center/axis to compression, extension, and support rows. Spread deformation across connected supports instead of one edge.

Prefer spacing existing rows before adding density. Shoulder and hip branching need the actual topology, not a cylindrical assumption. Test local weight changes with named valid groups and a declared protected region. Keep normalization, influence count, and visible deformation as separate checks. Weight changes must not conceal a rest-shape defect.
