# Local adjustment method

Fix the source version, symptom, view direction, and motion before editing. Separate shape/connectivity, bones, weights, normals, image channels, and display. Record units, pivot, axis, and landmarks. Limit displacement to the diagnosed area and fade it to zero at protected boundaries; update dependent clothes, ornaments, supports, and keys where justified.

When the same topology’s basis changes, carry only justified displacement into related keys while preserving intended relative motion. After topology edits, old vertex-indexed weights and keys require proven correspondence. For AO blotches, match lighting while disabling one AO/shadow/shading contribution at a time. For paint/UV problems, check stretch, flip, seams, and pattern direction; if UVs change, explicitly transfer or rebake affected paint. More resolution cannot fix incorrect mapping. Save dependencies, reopen, and compare matching views.
