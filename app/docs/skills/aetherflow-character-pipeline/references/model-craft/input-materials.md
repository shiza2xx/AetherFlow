# Input preparation

Collect the accepted art and model versions, front/side/back/oblique views, and closeups that show the issue. Label images as target, problem, accepted reference, candidate, or diagram. Keep scale, neutral pose, garment boundaries, finish, and asymmetry consistent.

Character generation requests the complete head with hair and the clothed body. Extra views may clarify a later local repair but do not create a second production route. Mark uncertain hidden construction as uncertain. Record units, coordinate frame, intended rig/rest state, UV/material links, shape-key dependencies, and output requirements. Use managed originals and verified disposable copies.
