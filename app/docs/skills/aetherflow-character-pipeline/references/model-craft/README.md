# AetherFlow modeling methods

This directory contains concise procedures for model work in AetherFlow. The active stage guide and source-bound evidence are authoritative; examples never provide character-specific dimensions, indices, colors, or weights.

Choose a focused procedure in `process-index.md`, define evidence in `quality-goals.md`, and prepare comparisons with `visual-handoff.md`. Geometry, skinning, image edits, saved-file verification, and target-engine behavior are separate claims.
