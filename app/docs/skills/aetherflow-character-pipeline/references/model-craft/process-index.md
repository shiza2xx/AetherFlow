# Procedure selection

Use the current accepted owner/source version and the exact stage prerequisites. For each change, state one goal, the allowed region, protected data, required poses/views, and evidence.

For new character work, prepare accepted views and references, create the manual mesh and segmentation, materialize required groups, assemble components with recorded transforms, fit the head, then rig and export the validated version. Keep results pending until their actual checks and human decisions complete.

Choose a method by cause: joint-flow checks for deformation; hand, eye, mouth, and hair procedures for local shape; material diagnosis before repainting; secondary motion only after the base rig behaves; and mesh repair for missing or incorrect surface structure. Texture and weight work use their source-bound receipts. After two attempts without improvement, revisit the cause instead of repeating coefficient changes.
