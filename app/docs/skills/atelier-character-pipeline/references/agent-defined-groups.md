# Agent-defined logical groups and regroup recovery

Group identities are not a fixed list of accessory types. Inspect the actual segmented geometry and original color design. The persisted head/upper_body/lower_body anchors and optional hair remain compatible; create additional groups with arbitrary unique safe keys and readable names through groupDefinitions [{key,name}]. The number and meaning come from this character, not example objects or a dropdown taxonomy. Several related components of one logical assembly can share one group. Unrelated objects need independent groups/models, front/back guides, color references, return slots and handoff folders. Keep a legacy accessories group readable; do not use it as a default bin for every unrelated object.

Read guided_workflow_get and its actual inventory. Use guided_components_list to search/filter/paginate compact IDs, current names, bounds and counts without dumping vertex/face arrays. Inspect uncertain exact IDs with guided_surface_run(mode=inspect-components, componentIds=[...], inputs=[accepted segmented head, accepted segmented body]). The tool supports at most eight IDs per inspection and returns isolated mesh-guide images and a copied scene; inspect their actual bytes. It does not change production assignments. Use bounds/material/source metadata as evidence, never classify by filename alone. Include every component exactly once in assignments and never mix head/body source frames within one group. Transfer whole saved components; if a desired boundary lies inside a connected component, follow ../../atelier-mesh-repair/references/segmentation-groups.md for inspected face selection and verified boundary repair; whole-component extraction alone is insufficient.

Use prepare-groups for the first partition. For an explicitly requested correction to existing groups at stages 8–10, use repartition-groups with both current accepted segmented sources, complete assignments, all custom groupDefinitions and the current expectedRevision. The operation checkpoints its managed input, saves new group models/guides and checks complete component coverage and preserved world surfaces/UVs/materials/normals. It retains old bytes and candidate history, preserves user approvals of existing paint images, attaches a group-change review notice, and invalidates changed-group geometry-dependent returns/handoffs plus assembled downstream proofs. Recheck paint against current guides; regenerate only actual visual mismatches. It returns to stage 8 for human review before Continue; never bypass adoption or silently reuse an old assembled model. Later rigged-stage regrouping is not covered by this pre-rig operation.

At stage 9 the actual selected mesh/group inventory defines which parts must be painted. Do not insert a generic 'no belt', 'no accessories', or another exclusion solely because a successful prompt used it for a different group. If an item belongs to this mesh, preserve it; if its assignment is wrong, repair the managed grouping and regenerate only the affected references. Do not conceal missing geometry or wrong assignments by painting the object away. Preserve intentional lace, glass, material boundaries and original color style. Report each group's actual name, exact slot state and outstanding checks; a readable pending draft is not accepted production output.


Before finalizing groups or painted group projections, read `../../atelier-mesh-repair/references/segmentation-groups.md`: inspect actual group-colored partition overviews and uncertain small pieces; verify hair/skin/cloth boundaries, all jewelry and authored material zones. For a wrongly attached connected surface, use the inspected face-selection repair route before regrouping rather than stopping at the whole-component tool limit. Preserve existing human image approvals after partition changes; inspect current guides and regenerate only actual image mismatches. Two-thirds silhouette coverage of an opaque group is an unfinished draft, not a ready handoff.
