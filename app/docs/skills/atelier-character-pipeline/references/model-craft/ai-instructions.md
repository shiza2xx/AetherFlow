# Correction request format

Give the accepted model and art versions, matched front/side/oblique views, closeups, and target format. Label target, defect, candidate, and diagrams separately. Identify units, axes, allowed region, dependent objects/bones/keys/materials, and protected data.

State the local goal, baseline, permitted edit, invariants, direction/fade of the change, comparison conditions, deliverables, and acceptance/re-diagnosis rule. Define ambiguous terms such as “back”, “round”, “preserve weights”, and “fix clipping” with coordinates, landmarks, exact values versus rules, and visible boundaries. Report measured differences outside the region. Keep the request, source identity, result, adoption status, and unverified conditions together.
