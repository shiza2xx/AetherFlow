# Quality goals and acceptance

Before editing, record target use, common viewing distance, required motions or expressions, and priority region. State source version/hash, editable and protected areas, matched comparison views, units, allowed differences, and save/reopen evidence.

Check rest, representative intermediate states, required extremes, and return to neutral. Include only combinations relevant to the requested work. Separate visual improvement, structural checks, saved-file verification, and engine/runtime results. Reopen the final candidate and regenerate evidence from that exact hash. Do not lower a goal to describe a failed result as complete.
