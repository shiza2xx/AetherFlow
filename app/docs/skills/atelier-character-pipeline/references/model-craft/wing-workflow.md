# Optional wing structures

Use only when the accepted character has wings and the correction requests them. Record outline, attachment, joints, upper/under surfaces, and rows in open, partial, and folded states. Build a support with real thickness and coherent joint motion before feather detail; test a small neighboring group first.

Keep roots seated, fade reshaping toward free blades, and coordinate row order/weights across joints. Separate folding, flapping, and tip flex. Verify root coverage, side/upper/under views, intersections, and clearance. Complete UV/material work after basic shape and following. Reopen, test export, and state unverified controls. Do not use example counts or angles as defaults.
