# Knee support flow

Use the accepted knee mesh and bone axis. Follow the same rows through rest, an intermediate bend, maximum required bend, and return. Mark compression, extension, and adjacent support. A diagram line is not changed geometry.

Reposition existing rows when they can distribute the fold; add a loop only when the required curvature cannot otherwise be represented. Avoid poles or thin faces at the strongest bend. Compare silhouette, fold, garment overlap, and twist. Do not reuse sample counts, dimensions, or weights. Reopen the candidate and verify motion before adoption.
