# Optional secondary motion

Start from the accepted mesh and rig. Mark fixed roots, ties, boundaries, and moving lengths. Verify base skeletal motion with secondary motion disabled. Then test neighboring strands or feathers across entry, intermediate, hold, return, and settling. Added bones or stronger values do not repair a misplaced attachment boundary.

Keep motion groups distinct from texture groups. Consolidate rigs/exports only on duplicates with explicit bone maps and verified mesh/weight/parent preservation. Record clip duration, sampled poses, and controls not tested in the target runtime. Settings, baked animation, and real-time behavior are separate results.
