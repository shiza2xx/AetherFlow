# Visual evidence handoff

Capture the accepted target and candidate at identical camera, pose, lighting, and useful distance. Include the failing intermediate, plain/wire closeup when topology matters, and protected features. Each image records role, model hash, view/pose, region, and interpretation.

Before integration, align mesh version, joint axes/rest pose, weighting rules or exact values, keys, normals, modifiers, constraints, and dependent details. Classify preservation as exact, within a stated tolerance, or unverified. Reopen the saved file and regenerate evidence from it. Verify export bytes, images, materials, rig, and actions separately. A Blender screenshot does not establish Unity parity.
