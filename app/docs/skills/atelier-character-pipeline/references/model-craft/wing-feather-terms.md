# Feather placement language

Define body-relative front/back, root/tip, and upper/under before naming groups. Separate outer/inner flight regions, cover rows, and any leading-edge group that actually exists. Track overlap among cover rows and long roots, neighbors within each row, and upper/lower coverage independently; directions can differ.

Map each term to the current design’s landmarks. Anatomy can explain a relationship without requiring a stylized character to use fixed counts. Test neighboring roots in rest, intermediate, and folded poses; record root coverage separately from blade exposure and silhouette.
