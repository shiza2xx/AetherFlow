# Assembly, returned rigs and weights

Use at steps 7–8, 10–13 and 15. Read the common pipeline and relevant model-craft references. Old vertex IDs, names, weights and millimeters are case history, not defaults.

Read ../atelier-character-pipeline/references/model-craft/personal-preservation-methods.md for transport surface maps, static-parent height restoration with keyed armature scale and anatomically bounded local transfer.

1. Checkpoint and fingerprint topology, corner order, UVs, materials, transforms, rig/rest matrices, weights, keys and actions on copies.
2. Inspect returned manual Tripo segments as a new baseline. Inventory components deterministically; semantic classification requires visual evidence. Inspect scale, neck junction and placement before grouping. Record any differing head/body coordinate frames and keep group provenance explicit: grouping alone does not fix them. The mandatory Stage10 head-fitting gate resolves placement before rig export. If an earlier segmentation correction is deliberately adopted, preserve old models and rebuild groups/guides from the new baseline. Never guess an anatomical fit from bounds or silently move accepted components.
3. Let the agent determine this character's logical objects: preserve the anatomical compatibility anchors, then create as many independently named groups as its actual geometry/design requires, using arbitrary safe keys and groupDefinitions. Several connected components of a single compound object can share a group; unrelated objects must not be collapsed into one accessories bucket. Keep lower outfit/legs/shoes together unless the actual group design calls for a separate logical object. Inspect exact component IDs through guided_components_list and inspect-components, and use revision-bound repartition-groups to recover a wrong stage8 partition at stages 8–10. Read ../atelier-character-pipeline/references/agent-defined-groups.md. Partition every saved component exactly once, preserving geometry, UVs, normals and material assignments. Motion groups are independent. Do not mix head/body coordinate systems.
4. Export group copies without welding and matched front/back mesh guides. Fix triangulation on those derivatives before exporting: preserve vertex positions, source-face/component provenance, UV corners, normals and material assignment. Save the same triangulated group baseline used for the handoff; accepted segmented originals remain unchanged. User runs Smart UV then retexture, without remesh.
5. Prove returned face/corner/position correspondence before restoring surfaces. Reordering/seam splits require verified maps. Count/bounds alone are insufficient; ambiguous/missing faces block.
6. Assemble returns with recorded transforms, retaining component lineage. Surface restoration preserves the group baseline coordinates: it does NOT place the head anatomically. Stage10 must explicitly fit the head to the body before rig export. Use `guided_head_fit_run` to create a checkpointed new fitted candidate from the exact accepted textured assembly. Apply one shared world transform to every declared head-source group (including hair and any head-source accessories); keep body-source groups fixed. Never guess accessory provenance, fit from bounds automatically, or move hair independently. Inspect front, side and back against the source artwork for proportions, neck junction and attachment positions. Human confirmation must bind to the exact fitted candidate/hash and its source assembly; a new candidate or changed source invalidates that confirmation. Use fit_head.py for transform-only preservation checks with reopened output. It proves saved geometry/material preservation, not anatomical correctness or welded topology. If the neck needs welding or reshaping, request a separate versioned correction and establish a new corresponding baseline. Preserve the textured master; Stage11 exports only the confirmed fitted version as a separate mesh-only rig copy with an immutable surface baseline. Rig generation never substitutes for head placement.
7. Compare returned rig geometry against that exact baseline. Preserve returned skeleton/rest pose/skin/actions. Restore materials and baseline corner normals only after proof, then independently audit. The independent returned-rig check compares local geometry, skin and complete animation controls to the raw returned rig, and every actual surface corner, UV, normal and material/image graph to the hashed pre-rig baseline. A single static scale/translation parent is allowed only with complete hierarchy proof; constrained/driven global alignment needs a separate motion audit. Do not compare newly generated weights to the unrigged model or silently waive legacy checks.
8. Diagnose rest/intermediate/maximum-required/return poses. Separate shape, topology, bones, weights, normals and paint. Edit explicit local regions, preserving unaffected weights.
9. Use guided_surface_tools.py, exact fingerprint/UV/join/validator scripts and mesh_quality_tools.py observations. Local weight cleanup needs topology fingerprint and explicit groups/vertices. Barycentric transfer is optional and bounded, never blanket donor replacement.
10. Reopen/export/reimport. Preserve all GLB influences before an explicitly declared target limitation. Register candidates/reports and leave adoption to the human.

Guided stage health audits are read-only model checks: texture work preserves geometry, UVs, corner normals, skin and rig controls; weight work preserves geometry, UVs, normals, material/image graphs and rig controls. They validate actual assigned PBR graphs/images or normalized valid-bone weights. They do not claim visual perfection or prove a local mask for an externally edited model. Keep stronger operation-specific mask/local-edit receipts when using the guarded repair scripts, then require human visual adoption. An unchanged model still needs the actual health check before the human no-repair decision completes the step.


Before finalizing groups or painted group projections, read `../atelier-mesh-repair/references/segmentation-groups.md`: inspect actual group-colored partition overviews and uncertain small pieces; verify hair/skin/cloth boundaries, all jewelry and authored material zones. For a wrongly attached connected surface, use the inspected face-selection repair route before regrouping rather than stopping at the whole-component tool limit. Preserve existing human image approvals after partition changes; inspect current guides and regenerate only actual image mismatches. Two-thirds silhouette coverage of an opaque group is an unfinished draft, not a ready handoff.
